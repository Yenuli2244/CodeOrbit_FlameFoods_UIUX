# CodeOrbit Tech - UI/UX Design Internship

## 📌 Project Overview
This repository contains the UI/UX design tasks completed during my 1-month UI/UX Design Internship at **CodeOrbit Tech** (Batch 3).

### ✅ Completed Tasks
1. **Task 1: Mobile App Wireframe Design (Food Delivery App)**
   - Designed a 6-screen low-fidelity wireframe flow (Profile, Menu, Food Details, Order Details, Delivery Address, and Payment) with user interaction notes.
2. **Task 2: High-Fidelity Landing Page UI Design (Flame Foods)**
   - Designed a dark-themed, vibrant orange (`#FF5107`) high-fidelity landing page featuring a Hero section, Special Combos, Menu, Customer Reviews, and Footer, along with a complete Style Guide and exported UI assets.

## 🛠️ Technologies & Tools Used
